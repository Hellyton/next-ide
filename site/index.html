Open source · macOS

Todas as sessões do Claude Code. Uma janela.

Uma IDE nativa para macOS que roda o seu próprio claude em todos os seus projetos, lado a lado. Chat, painéis divididos, terminal, arquivos e Git, sem uma parede de abas de terminal.

Baixar para macOS Estrela no GitHub

Grátis · MIT · Apple Silicon e Intel · macOS 13+ · assinado e notarizado

Uma mesa para cada projeto.

  1. Sessões lado a lado

    Cada projeto fica na barra lateral, agrupado em workspaces. Abra quantas sessões do Claude quiser e divida a tela com ⌘\. Você vê de relance qual está trabalhando, esperando ou pronta.

  2. Permissões no chat

    O Claude pede antes de rodar algo arriscado, bem onde você está lendo. Permita uma vez, sempre neste projeto, ou negue. Os modos manual, aceitar edições, plan e auto estão a um ⇧Tab.

  3. Todos os comandos /

    /resume, /rewind, /context, /model, /mcp e o resto do CLI, além de menções com @ para arquivos e subagentes, colar imagens e tarefas em segundo plano.

  4. Arquivos e um terminal de verdade

    Árvore de arquivos, visualizador e editor rápidos com destaque de sintaxe, ⌘P para abrir arquivos e um terminal zsh em qualquer painel. O layout volta igual na próxima vez que você abrir o app.

  5. Commit sem sair

    Revise o diff que o Claude acabou de fazer, selecione, faça commit e push pelo painel Git ao lado do chat. Troque de branch pela barra de status.

É o seu Claude Code. Só que mais.

O next-ide não reimplementa nada. Ele comanda o binário claude que você já tem, pelo Agent SDK oficial.

next-ide→Agent SDK→seu claude→API da Anthropic

Seu login
Pro, Max ou API key, o que o claude já usa. O next-ide nunca vê nem guarda.
Sua configuração
CLAUDE.md, hooks, servidores MCP, skills e regras de permissão carregam igualzinho ao terminal.
Mesma velocidade
Mesmo modelo, mesmo cache de prompt. As sessões aparecem no /resume do CLI, e o contrário também.

Instale em um minuto.

  1. 1

    Tenha o Claude Code instalado e logado. Rodar claude no terminal tem que funcionar.

  2. 2

    Baixe o DMG do seu Mac (Apple Silicon ou Intel) e arraste o next-ide para Aplicativos. Ele é assinado e notarizado, então abre como qualquer app.

  3. 3

    Crie um workspace, adicione a pasta de um projeto e aperte ▶. Pronto, é uma sessão do Claude.

Prefere compilar você mesmo?

Dúvidas.

É mais lento que o CLI?

Não. Cada sessão é o seu próprio claude rodando por trás do Agent SDK, então as respostas demoram o mesmo que no terminal. A primeira mensagem de uma aba nova espera um ou dois segundos enquanto o CLI inicia e carrega seus servidores MCP.

Precisa de assinatura?

Precisa do mesmo que o Claude Code precisa. Se o claude funciona no seu terminal, com plano Pro ou Max ou com uma API key, o next-ide funciona também.

Para onde vão meus dados?

Para lugar nenhum novo. Sem contas, sem servidores, sem telemetria. Workspaces e configurações ficam no seu Mac; as conversas são guardadas pelo próprio Claude Code em ~/.claude.

Windows ou Linux?

Ainda não. Por enquanto o app é só para macOS. O código é MIT, e pull requests são bem-vindos.
