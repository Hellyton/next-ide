Every Claude Code session. One window.

A native macOS IDE that runs your own claude across all your projects, side by side. Chat, split panes, terminal, files and Git, without a wall of terminal tabs.

A desk for every project.

  1. Sessions side by side

    Every project lives in the sidebar, grouped into workspaces. Open as many Claude sessions as you want and split them on screen with ⌘\. You see at a glance which one is working, waiting or done.

  2. Permissions in the chat

    Claude asks before it runs something risky, right where you are reading. Allow once, always for this project, or deny. Manual, accept-edits, plan and auto modes are one ⇧Tab away.

  3. Every slash command

    /resume, /rewind, /context, /model, /mcp and the rest of the CLI, plus @ mentions for files and subagents, image paste and background tasks.

  4. Files and a real terminal

    A file tree, a fast highlighted viewer and editor, ⌘P quick open, and a zsh terminal in any pane. The layout comes back the next time you open the app.

  5. Commit without leaving

    Review the diff Claude just made, stage, commit and push from the Git panel next to the chat. Switch branches from the status line.

It's your Claude Code. Just more of it.

next-ide doesn't reimplement anything. It drives the claude binary you already have, through the official Agent SDK.

next-ide→Agent SDK→your claude→Anthropic API

Your login
Pro, Max or an API key, whatever claude already uses. next-ide never sees or stores it.
Your setup
CLAUDE.md, hooks, MCP servers, skills and permission rules load exactly like in the terminal.
Same speed
Same model, same prompt cache. Sessions appear in the CLI's /resume, and the other way round.

Install in a minute.

  1. 1

    Have Claude Code installed and logged in. Running claude in a terminal should work.

  2. 2

    Download the DMG and drag next-ide to Applications. It's signed and notarized, so it opens like any app.

  3. 3

    Create a workspace, add a project folder and press ▶. That's a Claude session.

Questions.

Is it slower than the CLI?

No. Each session is your own claude running behind the Agent SDK, so answers take as long as in the terminal. The first message in a new tab waits a second or two while the CLI starts and loads your MCP servers.

Does it need a subscription?

It needs whatever Claude Code needs. If claude works in your terminal, with a Pro or Max plan or an API key, next-ide works too.

Where does my data go?

Nowhere new. No accounts, no servers, no telemetry. Workspaces and settings stay on your Mac; conversations are stored by Claude Code in ~/.claude.

Windows or Linux?

Not yet. The app is macOS-only for now. The code is MIT, and pull requests are welcome.
